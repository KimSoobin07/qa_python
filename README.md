# BooksCollector — Юнит-тесты

Проект содержит тесты для класса `BooksCollector`, написанные с использованием фреймворка `pytest`. 

В ходе работы были покрыты все методы класса:
* `add_new_book` — добавление книги, запрет дублей, валидация длины имени (от 1 до 40 символов) с помощью параметризации.
* `set_book_genre` — установка валидного жанра и игнорирование невалидного.
* `get_book_genre` — получение жанра существующей книги и возврат `None` для отсутствующей.
* `get_books_with_specific_genre` — получение списка книг по жанру (с применением параметризации).
* `get_books_genre` — получение текущего словаря книг.
* `get_books_for_children` — фильтрация книг без возрастного рейтинга.
* `add_book_in_favorites` — добавление книги в избранное (игнорирование дублей и несуществующих книг).
* `delete_book_from_favorites` — удаление книги из избранного.
* `get_list_of_favorites_books` — получение списка избранных книг.

Для запуска тестов из терминала используйте команду:
